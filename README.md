# data_maestra_prueba
Prueba técnica data engineer
Se añaden los 5 archivos SQL para ejecución de los queries solicitados. La información consume data del proyecto data_maestra_prueba y el dataset data_maestra para resolver los enunciados en cada nivel indicado bajo sentencias SQL.

Para el caso en cuestión se tomaron las siguientes consideraciones:
1. Se valido que los campos tengan el tipo correctamente asignado antes de realizar la carga en GCP, así también se divieron en CSV individuales para cargar cada hoja como una tabla individual.
2. Se identificaron las anomalías mencionadas en el enunciado para evitar considerarlas en los cálculos y genrerar distorciones.
3. Se utilizó el formato estándar camel_case para los nombres de las tablas y mantener un orden en las estructuras de datos.
